mUnix OS

v0.7.0 — A minimalist bare-metal operating system.

mUnix is a lightweight 32-bit Flat Protected Mode operating system built entirely from scratch. Operating strictly as a Live OS inside system memory, it bypasses legacy constraints to establish a clean, predictable, and zero-dependency environment.

Graphics Architecture VGA Mode 13h (320x200, 256 colors)
Virtual File System Hierarchical RAMFS (mkdir, cp, cd, pwd)
Peripheral Drivers Native PS/2 Mouse & Keyboard Controller
Hardware Probing Real ATA IDENTIFY & CPUID validation
Integrated Tools Media Player, Paint, Games, Core Panic
